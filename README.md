# Prefere — сайт камерного оркестра

Одностраничный (landing) сайт оркестра **Prefere**: афиша, репертуар, состав, записи и контакты.

## Структура

```
index.html      — главная страница
css/style.css   — стили (адаптивная вёрстка, тема «тёмное дерево + золото»)
js/main.js      — интерактив: мобильное меню, табы репертуара, анимации, форма
```

## Запуск локально

```bash
python3 -m http.server 8080
# откройте http://localhost:8080
```

Либо просто откройте `index.html` в браузере.

## Секции сайта

1. **Hero** — название оркестра и слоган («Prefere» = «я предпочитаю»)
2. **О нас** — концепция и факты (год основания, концерты, состав, гастроли)
3. **Афиша** — ближайшие концерты с кнопками «Билеты»
4. **Репертуар** — вкладки: классика, неоклассика, музыка кино, аранжировки
5. **Состав оркестра** — карточки групп музыкантов
6. **Записи и медиа** — превью видео/альбомов
7. **Проекты** — абонементы, образование, частные события, коллаборации
8. **Контакты** — форма обратной связи и реквизиты

## Доработка под реальный оркестр

- Замените тексты, даты концертов, имена музыкантов и контакты на реальные.
- Добавьте фото: замените заглушки `.card-photo.placeholder` и `.thumb` на `<img>`/видео-плееры.
- Подключите отправку формы к бэкенду или сервису (например, Formspree).
